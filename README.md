# 我们的厨房 · Our Kitchen

给两个人用的私人点菜网页：管理菜品和照片、长按分类排序、收藏喜欢的菜、提交点菜清单，可选 Server 酱微信提醒

## 快速开始

Windows 10/11（x64 / ARM64）下载解压后，双击 **start.bat**，选择「开始」：

- **本机运行**：按提示设置管理员密码和访客暗语，自动安装依赖、构建并打开网页。
- **服务器运行**：填写 SSH 和网站信息，自动部署并配置 HTTPS；支持域名或公网 IP。

首次运行需要联网，缺少兼容的 Node 24 时会自动下载。「重新配置」修改设置，「运行管理」查看状态、更新或停止服务。关闭启动器不会停止已运行的服务。

本机默认地址：

- 点菜：<http://localhost:3001/order/>
- 后台：<http://localhost:3001/order/admin>

初始菜单为空，请登录后台添加菜品。微信提醒可在配置时填写 [Server酱 SendKey](https://sct.ftqq.com/sendkey)，不填也能正常下单。

演示地址：<http://127.0.0.1:5173/order/>；访客暗语 `一起好好吃饭`，管理员密码 `demo-chef-2026`。演示仅本机可用，不发送微信。设计约定见 [DESIGN.md](DESIGN.md)
